# API-JWT — Frontend

SPA en React + Vite + Tailwind CSS que consume la API de `../backend`.

Ver la documentación completa del proyecto en el [README principal](../README.md).

## Comandos

```bash
npm install
cp .env.example .env   # ajusta VITE_API_URL si es necesario
npm run dev             # http://localhost:5173
npm run build            # build de produccion en dist/
```
